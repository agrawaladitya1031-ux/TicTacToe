
# TicTacToe

A console-based, two-player Tic-Tac-Toe game developed in C++.

## Features

- Two-player gameplay
- 3x3 game board
- Automatic win detection
- Draw detection
- Input validation
- Prevention of moves on occupied positions

## Technologies Used

- C++
- Two-dimensional arrays
- Functions
- Loops and conditional statements

## How to Run

Compile:

    g++ main.cpp -o tictactoe

Run on Windows:

    tictactoe.exe

Run on Linux or macOS:

    ./tictactoe

## Rules

- Player X starts the game.
- Players take turns selecting positions 1-9.
- The first player to get three marks in a row,
  column, or diagonal wins.
- If all nine positions are filled without a winner,
  the game ends in a draw.

## Learning Outcomes

This project demonstrates array manipulation,
game logic, input validation, and function-based
program design.
